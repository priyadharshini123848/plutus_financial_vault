ADMIN MONEY VIEW:
- TOTAL USER FUNDS = sum of current balances of all regular users.
- TOTAL DEPOSITS, TOTAL WITHDRAWALS and TOTAL TRANSFERS are separate totals.
- Each user row shows name, email, account details, current balance, deposits, withdrawals, transfers, net total and latest transaction times.
- Edit User Details opens an editable form for name, email, account number, account type and balance.
- The detailed Money Activity table shows every user deposit, withdrawal and transfer with exact IST date/time.
- Admin's own balance remains separate from user funds.

No demo users or demo transaction data are included in the database.
